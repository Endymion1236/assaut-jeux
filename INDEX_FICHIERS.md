5. `.env.local` - Tes clés Firebase

## 📝 ORDRE RECOMMANDÉ DE CRÉATION

```
1. Crée les dossiers (voir STRUCTURE_FICHIERS.md)
2. Place les fichiers config à la racine
3. Place public/index.html
4. Place src/index.js
5. Place src/App.jsx
6. Place toutes les pages dans src/pages/
7. Place tous les composants dans src/components/
8. Place tous les CSS dans src/styles/
9. Place config/data/utils dans leurs dossiers
10. Crée .env.local avec tes clés Firebase
11. Lance npm install
12. Lance npm start
```
